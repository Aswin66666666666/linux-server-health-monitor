# Linux Server Health Monitor

A Linux server monitoring project built using Bash, Python, Flask, JavaScript, and Nginx. The project collects system resource information and displays it through a real-time web dashboard.

## Features

- CPU usage monitoring
- RAM utilization monitoring
- Disk usage monitoring
- Network traffic monitoring
- System uptime and load average
- Real-time resource charts
- Resource usage thresholds and visual alerts
- Linux service monitoring
- Monitoring of Nginx, MariaDB, PHP-FPM, and SSH
- Automated Bash monitoring using systemd
- Log management using logrotate

## Technologies Used

- Linux (Astra Linux / Rocky Linux compatible environment)
- Bash
- Python
- Flask
- HTML
- CSS
- JavaScript
- Chart.js
- Nginx
- systemd
- logrotate

## Architecture

Linux System Metrics → Python/Flask API → JavaScript Dashboard

Nginx acts as the web server and reverse proxy for the dashboard.

## Project Purpose

The purpose of this project is to monitor Linux system resources and important services through a centralized web dashboard, reducing the need to manually execute multiple system monitoring commands.

## Project Status

Completed as a Linux administration and monitoring lab project.
